# Manual das 72 Horas — site estático

Site pronto para publicar, sem etapa de build. A página inicial é `index.html`.

## GitHub
Suba o conteúdo desta pasta na raiz do repositório (arquivos soltos, sem pasta extra).

## Cloudflare Pages
1. Cloudflare > Workers & Pages > Create > Pages > Connect to Git, e escolha o repositório.
2. Framework preset: None.
3. Build command: deixe em branco.
4. Build output directory: `/` (a raiz).
5. Deploy.

Alternativa: Pages > Upload assets, e arraste esta pasta (ou o zip extraído).
